# Task 1: Create a Basic Project Design

**Status:** Complete  
**Task type:** Dashboard design

## Objective

Create a simple, responsive dashboard design for GeoPulse that communicates
the project's intended hyper-local retail mobility analytics workflow before
connecting or analyzing real data.

## Design requirements

- Show an overview of footfall, activity times, dwell time, and local areas.
- Include a mobility activity chart, an illustrative activity map, and a ranked
  list of areas.
- Provide a reporting-period selector and a sample report export.
- Work across desktop and mobile screen sizes.
- Clearly identify all sample figures and map visuals as illustrative.

## Completion criteria for this task

- The dashboard prototype is available from `index.html`.
- Key dashboard sections and basic interactions are present.
- Illustrative content is not presented as verified project findings.
- The layout remains usable on narrow screens.

## Project context

GeoPulse proposes an end-to-end analytics workflow: data collection, cleaning
and validation, exploratory and geographical analysis, visualization,
dashboard development, and business reporting. The project brief does not yet
identify a dataset, business question, geographic area, analysis period, or
dashboard audience.

## Inputs still needed before connecting real data

The business question, dataset and source, geographic area, analysis period,
dashboard audience, and metric definitions must be established before replacing
the sample content or making project-specific claims.

## Result

The basic GeoPulse dashboard design is complete. Its sample metrics and map are
for layout demonstration only and do not represent actual analysis.
