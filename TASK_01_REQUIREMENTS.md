# Task 1: Understand Project Requirements

**Status:** Complete  
**Task type:** Project initiation and documentation

## Objective

Establish a clear baseline for the GeoPulse data analytics project from the
provided project brief, before collecting or analyzing data.

## Requirements captured

The project is intended to provide practical experience with an end-to-end
data analytics workflow:

1. Understand the project objectives and requirements.
2. Collect, clean, and validate data from relevant sources.
3. Analyze data and create meaningful visualizations.
4. Develop interactive dashboards and analytical reports.
5. Identify trends, patterns, and actionable insights.
6. Document the analysis and reporting process.
7. Share progress with the mentor and complete work within the project timeline.

Expected final deliverables are source code (if applicable), project
documentation, a project report, a presentation, model evaluation results (if
applicable), and a final demonstration (if applicable).

## Completion criteria for this task

- The project objective and expected workflow are recorded.

- No dataset, business question, or geographic scope is assumed without evidence.

## Evaluation criteria

The brief identifies attendance and punctuality, technical competency, quality
of deliverables, innovation and problem-solving, communication and teamwork,
adherence to timelines, documentation standards, and the final review and
presentation.
